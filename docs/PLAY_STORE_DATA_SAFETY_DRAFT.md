# Data Safety working draft — verify against final implementation

Potential collected data includes: account identifiers/email; profile data; user-generated messages/resources/reviews; approximate/offline meetup location chosen by the user; device push token; app activity/diagnostics if analytics is enabled.

Purposes may include account management, core app functionality, security/fraud prevention, communications, personalization/recommendations and analytics.

This is a working engineering inventory, not a completed legal declaration. The final Play Console answers must exactly match the production build, enabled SDKs, retention rules and privacy policy.
