# SkillBridge Next-Gen Visual Asset Pack v2 — Expansion

This pack adds more **GIF and image resources** for the current SkillBridge Next-Gen implementation. It is an expansion, not a replacement for v1.

## Included
- 12 hero banners
- 20 feature cards
- 12 mobile wallpapers/backgrounds
- 18 animated GIFs
- 18 community/achievement stickers
- 12 reaction stickers
- 10 transparent avatar frames
- 12 status badges
- 10 notification illustrations
- 8 new empty states
- 20 transparent decorative elements
- 8 section banners
- AI-generated visual pack preview

## Rules for Antigravity
- Keep the existing SkillBridge brand and theme tokens.
- Integrate selectively; do not dump every asset onto every screen.
- Avoid more than one or two active GIFs in the viewport on low-end Android.
- Respect reduced-motion settings.
- Use static feature cards and section banners in lists.
- Use avatar frames as transparent overlays.
- Lazy-load heavy visual assets where possible.
