# Screen → asset mapping

| Screen / state | Suggested asset | Usage |
|---|---|---|
| Home / first visit | `home-network.png` | Premium hero / campaign carousel |
| Room detail landing | `study-room.png` | Five-module explainer only |
| Live room | `live-class.png`, `live-pulse.gif` | Pre-live lobby + status |
| Q&A empty | `no-chat.png` or `qna-board.png` | Empty state / feature onboarding |
| Materials empty | `no-materials.png` | Empty state |
| Recordings empty | `no-recordings.png` | Empty state |
| Club landing | `club-os.png` | Club OS explainer |
| Event publish warning | `clash-engine.png`, `clash-warning.png` | Conflict modal / admin workflow |
| Offline | `offline.png` | Offline-first state |
| Global loading | `loader-orbit.gif` | Cold start/auth restore only |
| Success | `success-confetti.gif` | Short one-shot feedback |

Avoid automatic looping GIFs in feeds and long lists; they increase decode/battery cost.
