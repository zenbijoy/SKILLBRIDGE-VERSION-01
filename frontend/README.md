# SkillBridge Expo Frontend

Cross-platform React Native + Expo frontend for Android, iOS and Web.

## Setup
1. `cp .env.example .env`
2. Set Supabase URL/anon key and API URL.
3. `npm install`
4. `npx expo install --check`
5. `npx expo prebuild --platform android --no-install` when native config changes (required for LiveKit native modules)
6. `npm run android`, `npm run ios`, or `npm run web`.

Expo Go is not sufficient for the LiveKit native module. Use a development build.

The Android directory is intentionally checked in, while iOS is generated by EAS. The
`withReleaseSigning` config plugin preserves the fail-closed `MYAPP_UPLOAD_*` release
signing configuration whenever Android is regenerated. Review the native diff after
every prebuild; never ship an Android release signed with the debug key.
